# اكتشف اليمن - Discover Yemen

## نظرة عامة

مشروع "اكتشف اليمن" هو نظام إدارة سياحية/معلوماتية مبني باستخدام ASP.NET Core MVC.
يهدف المشروع إلى تقديم منصة شاملة لاكتشاف المعالم السياحية والفنادق والمطاعم والفعاليات في اليمن.

### البنية المعمارية

- **ASP.NET Core MVC** - إطار العمل الرئيسي
- **Entity Framework Core** - ORM للتعامل مع قاعدة البيانات
- **ASP.NET Core Identity** - نظام المصادقة والتفويض
- **SQLite** - قاعدة البيانات
- **Bootstrap 5 RTL** - واجهة المستخدم

### الوحدات الرئيسية

1. **إدارة المحافظات** - عرض وإدارة المحافظات اليمنية
2. **إدارة المعالم السياحية** - CRUD كامل مع رفع الصور
3. **إدارة الفنادق** - عرض وإدارة الفنادق
4. **إدارة المطاعم** - عرض وإدارة المطاعم
5. **إدارة الفعاليات** - عرض وإدارة الفعاليات
6. **نظام المفضلة** - إضافة/إزالة المعالم من المفضلة
7. **نظام التقييمات** - تقييم المعالم السياحية
8. **نظام الحجوزات** - حجز المعالم والفنادق والفعاليات
9. **لوحة التحكم** - إدارة شاملة للمسؤول
10. **التقارير** - إحصائيات وتقارير من قاعدة البيانات

---

## الأهداف

### أهداف المشروع

- تطوير منصة سياحية شاملة لليمن
- تطبيق مفاهيم البرمجة المرئية باستخدام ASP.NET Core MVC
- تنفيذ نظام مصادقة وتفويض متكامل
- تطبيق عمليات CRUD كاملة مع رفع الصور
- استخدام Entity Framework Core مع العلاقات المختلفة

### مجال المشكلة

اليمن بلد غني بالتراث والمعالم السياحية لكن يفتقر لمنصات رقمية شاملة تعرض هذه المعالم.
هذا النظام يوفر حلاً لعرض وإدارة المعلومات السياحية بشكل منظم.

## دليل المستخدم

### 1. تشغيل المشروع

```bash
cd DiscoverYemen
dotnet restore
dotnet build
dotnet run
```

### 2. التسجيل

- افتح الموقع في المتصفح
- اضغط "إنشاء حساب" من القائمة
- أدخل الاسم والبريد الإلكتروني وكلمة المرور
- اضغط "إنشاء حساب"

### 3. تسجيل الدخول

- اضغط "تسجيل الدخول" من القائمة
- أدخل البريد الإلكتروني وكلمة المرور
- اضغط "تسجيل الدخول"

### 4. عرض المحافظات

- اضغط "المحافظات" من القائمة
- استخدم البحث لتصفية المحافظات
- اضغط "عرض التفاصيل" لرؤية محتوى المحافظة

### 5. عرض المعالم

- اضغط "المعالم" من القائمة
- استخدم الفلاتر (محافظة، تصنيف، بحث)
- اضغط "عرض التفاصيل" لرؤية تفاصيل المعلم

### 6. البحث والتصفية

- استخدم حقل البحث في صفحة المعالم
- اختر المحافظة من القائمة المنسدلة
- اختر التصنيف من القائمة المنسدلة
- اضغط "بحث"

### 7. إضافة/إزالة المفضلة

- سجل الدخول أولاً
- افتح تفاصيل أي معلم
- اضغط "أضف للمفضلة"
- لعرض المفضلة: اضغط "المفضلة" من القائمة
- لإزالة عنصر: اضغط "إزالة"

### 8. إرسال تقييم

- سجل الدخول أولاً
- افتح تفاصيل أي معلم
- اختر التقييم (1-5 نجوم)
- اكتب تعليقك
- اضغط "إرسال التقييم"

### 9. عرض الحجوزات

- سجل الدخول أولاً
- اضغط "حجوزاتي" من القائمة
- أو احجز من صفحة تفاصيل المعلم/الفندق/الفعالية

### 10. تسجيل الدخول كمسؤول

- البريد: admin@discoveryemen.com
- كلمة المرور: Admin@123

### 11. إدارة المعالم (مسؤول)

- سجل الدخول كمسؤول
- اضغط "لوحة التحكم"
- اذهب إلى "المعالم"
- استخدم أزرار الإضافة/التعديل/الحذف

### 12. رفع/تحديث/حذف الصور

- في صفحة إضافة/تعديل المعلم
- اختر ملف صورة من جهازك
- عند التعديل: الصورة القديمة تُحذف تلقائياً
- عند حذف المعلم: الصورة المرتبطة تُحذف

### 13. عرض التقارير

- سجل الدخول كمسؤول
- اذهب إلى "التقارير" من لوحة التحكم
- شاهد الإحصائيات والأرقام
